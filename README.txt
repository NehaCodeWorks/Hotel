# Noida Dreamz Guest House — website demo

A responsive, animated static website built with HTML5, Bootstrap 5, custom CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet is needed for Bootstrap CDN, Google Fonts and sample Unsplash images.

## Before showing/publishing to the hotel
- Confirm the hotel has approved the use of its name and branding for a public demo.
- Replace sample Unsplash images with owner-approved real property photographs.
- Confirm the full address, phone, room categories, capacity, prices, check-in/out timings and actual amenities.
- Remove or rewrite any section that does not match the property.
- In `js/script.js`, set `HOTEL_WHATSAPP_NUMBER` to the hotel's verified WhatsApp number (digits only, including country code).
- Add a verified Google Maps embed/link if the owner wants it.
- Review all template/image licences and terms before commercial use.

## Important
This is an unofficial concept/demo, not an approved or live booking system. It has no backend, database, payment processing or real-time room availability. The enquiry form opens WhatsApp after a verified number is configured.
